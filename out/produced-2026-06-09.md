## Übersicht

Die Dark-Factory `df-heylou-mistral-extension` integriert HeyLou als Sub-Funktion in die Mistral Function-Calling API. Es ermöglicht DeepSeek und anderen LLM Plattformen, Anfragen an den HeyLou Travel Knowledge Graph zu richten.

## Funktionen

| Funktion               | Beschreibung                                                                                           | Backend                         |
|------------------------|---------------------------------------------------------------------------------------------------------|---------------------------------|
| `search_hotels`        | Sucht Hotels im Travel Knowledge Graph von HeyLou.                                                    | df-heylou-travel-domain       |
| `get_rates`            | Ruft die Preise für ein Hotel ab, basierend auf dem PMS/RMS System des Hotels.                        | df-pms-mews-adapter (Welle 36)|
| `compare_otas`         | Vergleicht OTAs wie Booking.com, Expedia und HRS mit der Preise und Verfügbarkeit eines bestimmten Hotels. | df-ota-* (Welle 37)            |
| `book_direct`          | Erlaubt eine kommission-freie Buchung direkt über HeyLou für ein Hotel.                             | df-heylou-travel-domain       |
| `optimize_revenue`     | Enthält einen Stub, der in Zukunft verwendet wird, um die Einnahmen eines Hotels zu optimieren.      | Welle 40 (Pending)             |

## Konfiguration

Die Verwendung des Real-Modus erfordert die Umgebungsvariablen `DF_HEYLOU_MISTRAL_EXT_ENABLED=true`, `PHRONESIS_TICKET` und `MISTRAL_API_KEY`. Ohne diese Einstellungen läuft der Modus im Mock-Simulation Modus.

### Sandbox-Modus

Für die Entwicklung und den Testbetrieb ist der Sandbox-Modus aktiviert:

```bash
DF_HEYLOU_MISTRAL_EXT_ENABLED=false  # Aktiviert den Mock-Simulation Modus.
```

## Bereitstellung

### Umgebungsvorbereitung
1. Stellen Sie sicher, dass die erforderlichen Python-Pakete installiert sind:
```bash
pip install -r requirements.txt
```
2. Legen Sie die Umgebungsvariablen `DF_HEYLOU_MISTRAL_EXT_ENABLED=true`, `PHRONESIS_TICKET` und `MISTRAL_API_KEY` fest.
3. Starten Sie den LaunchAgent mit dem Kommando:
```bash
launchctl load scripts/com.kemmer.df-heylou-mistral-extension.plist
```
4. Überwachen Sie die Protokolle im Verzeichnis `/var/log/system.log`, um sicherzustellen, dass der Agent korrekt ausgeführt wird.

### Aktivierung des Modus

Um den realen Modus zu aktivieren, setzen Sie `DF_HEYLOU_MISTRAL_EXT_ENABLED=true` und stellen Sie sicher, dass die erforderlichen API-Tokens (`PHRONESIS_TICKET`, `MISTRAL_API_KEY`) korrekt konfiguriert sind.

## Logging und Überwachung

Die Aktivität wird über einen Audit-Logger mit HMAC-SHA256 JSONL format aufgezeichnet. Dies gewährleistet, dass jede Funktionserfahrung authentifiziert und sicher protokolliert ist.
